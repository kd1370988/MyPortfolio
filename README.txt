ポートフォリオ：3作品の専用ページ更新セット
==========================================

この更新セットは、作品ページを次の3つに整理したものです。
1. works/silent-escape.html         — Silent Escape（ステルス脱出ゲーム）
2. works/silent-escape-audio.html   — Silent Escapeの音響システム
3. works/team-roguelike.html        — 1年次のチーム制作

同梱ファイル
- index.html: 作品カードを3件に整理し、専用ページへのリンクを設定
- style.css / script.js: トップと詳細ページで共通使用するファイル
- works/detail.css: 詳細ページ共通のレイアウト
- works/*.html: 3作品の専用ページ
- images/team-roguelike.svg: チーム作品画像の仮イラスト（あとで実際のゲーム画面に差し替え可能）

GitHub Pagesへの反映
1. 現在のリポジトリをバックアップしてから作業してください。
2. このセットの index.html、style.css、script.js をリポジトリのルートにコピーして置き換えます。
3. works フォルダーに、同梱の detail.css と3つのHTMLファイルを配置します。以前の works/game-engine.html、works/shutter-mirage.html、works/audio-awareness.html、works/stealth-escape.html は、この新構成ではリンクされません。必要ならバックアップを取ってから整理してください。
4. images/team-roguelike.svg だけを既存の images フォルダーへ追加します。既存の images フォルダーを丸ごと置き換えないでください。
5. 既存の画像（プロフィール、SilentEscape.png、SoundRay.png、hero-scene.svg）はリポジトリに残しておきます。
6. コミット・プッシュし、トップページの3つの作品カードと各専用ページ間のリンクを確認します。

注意
- チーム制作の画像は仮イラストです。実際のスクリーンショットがあれば差し替えてください。
- GitHub PagesはURLの大文字・小文字が区別されるため、画像名・リンク先の綴りを合わせてください。
- 制作期間など未確認の情報は記載していません。公開前に実際の内容と一致しているか確認してください。
