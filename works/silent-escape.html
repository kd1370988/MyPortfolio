01 — OVERVIEW

作品概要PROJECT SUMMARY

『Silent Escape』は、敵の追跡から逃れながら目的を達成し、脱出を目指す個人制作の3Dホラー・ステルスゲームです。

敵はプレイヤーが発生させた音に反応し、追跡をします。敵の位置や行動を考えながら、周囲の環境とアイテムを活用して行動するゲーム体験を目指しています。

  • 制作形態個人制作
  • 制作状況開発中
  • 主な使用技術C++ / DirectX 12 / HLSL / Enemy AI

02 — GAME SYSTEMS

主な実装KEY FEATURES

01 / FEATURE

聴覚による索敵

プレイヤーが発生させた音を敵が検知し、音源の位置などを手がかりに反応する。

02 / FEATURE

経路探索

敵がルートを決める際にマップ上のノード使ってA*アルゴリズムで探索する。

03 / FEATURE

スタングレネード

敵を一定時間スタンさせ、追跡を振り切って目的を達成するための隙を作るアイテム。

03 — DEVELOPMENT NOTES

開発で意識していることIMPLEMENTATION NOTES

敵AIは状態遷移を用いて管理し、プレイヤーを発見しているか、最後に認識した位置を追跡しているかなど、状況に応じて行動を切り替えます。

また、音響システムをゲームプレイに組み込み、プレイヤーの行動が敵の反応や追跡に影響するように開発しています。
