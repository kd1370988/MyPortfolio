AUDIO SYSTEMステルスゲームの音響システム

01 — OVERVIEW

システム概要AUDIO SYSTEM SUMMARY

これは独立したゲーム作品ではなく、『Silent Escape』に実装している音響システムです。音源からリスナーまで音が伝わる経路を計算し、直接音だけでなく、壁や床などで反射した音も扱います。

プレイヤーが発生させた音を敵が聞き、音源の位置などを手がかりに行動できるようにすることで、音の伝わり方をステルスゲームの駆け引きに結び付けています。

  • 使用箇所Silent Escape の聴覚システム
  • 主な使用技術C++ / DirectX 12 / HLSL / Audio Ray Tracing
  • 扱う要素音の反射経路 / 音量の減衰 / 敵の聴覚判定

02 — KEY FEATURES

主な処理HOW IT WORKS

01 / FEATURE

反射経路の追跡

レイトレーシングを利用して音の反射経路をレイで追跡し、直接音に加えて反射音を計算する。

02 / FEATURE

距離・素材による減衰

伝播距離やマテリアルに設定しているの吸音特性に応じて音量を弱め、聞こえ方に差を付ける。

03 / FEATURE

計算結果の使い方

リスナーをコンピュートシェーダーに渡し、GPU側で計算結果を用いて、敵の音の検知やプレイヤーに聞こえる音に反映している。

03 — TECHNICAL NOTES

技術的な工夫IMPLEMENTATION NOTES

音響システムでは、GPUを利用したレイトレーシングによって音の反射経路を計算し、 壁などの表面で反射した音がどの程度聞こえるかを再現しています。 音が伝わる距離に応じて音量を減衰させるほか、 反射する表面の吸音特性も計算に取り入れ、材質によって音の伝わり方が変化する仕組みを実装しています。

レイの反射回数には上限を設け、反射後の音量が一定のしきい値を下回った場合には 追跡を終了することで、影響の小さい反射音に対する計算を抑えています。 音の再現性だけでなく、計算負荷とのバランスも考慮しながら、 ゲーム内で利用できる音響計算の実現を目指しています。

GPU側で計算した音の到達情報や音量をゲーム側へ渡し、 敵AIの聴覚による索敵や、音の反射を表現する再生処理に利用しています。 これにより、プレイヤーが発生させた音が障害物などの影響を受けながら敵へ伝わり、 敵が音源の位置を調査するなど、音響計算が実際のゲームプレイにつながる構成にしています。

実装で特に苦労したのは、反射音の音量と敵の聴覚判定の調整です。 反射音が大きすぎると、離れた位置にいる敵まで音を検知してしまい、 プレイヤーの意図しないタイミングで追跡が発生する問題がありました。 そのため、距離による減衰や反射回数、音量のしきい値などを見直し、 音の聞こえ方と敵の反応がゲームとして自然になるよう調整しています。

調整で意識している点

音響現象を再現するだけでなく、プレイヤーが音を出すリスクと、 敵の位置や周囲の環境を考慮して行動する面白さを両立させることを意識しています。 計算結果を敵AIと連携させ、技術的な仕組みを新しいゲーム体験につなげることを目指しています。
